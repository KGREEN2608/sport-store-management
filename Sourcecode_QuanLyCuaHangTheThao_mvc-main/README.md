# Hệ thống Quản Lý Cửa Hàng Thể Thao

## Giới thiệu
Đây là dự án học tập thuộc chương trình **Công nghệ Phần mềm**.  
Dự án tập trung vào **phân tích yêu cầu và kiểm thử phần mềm (Manual Testing)** cho hệ thống quản lý cửa hàng thể thao.

Hệ thống hỗ trợ các chức năng cơ bản trong quản lý cửa hàng như quản lý sản phẩm, quản lý nhân viên và xử lý bán hàng.

---

## Mục tiêu
- Rèn luyện kỹ năng phân tích yêu cầu dựa trên nhu cầu người dùng
- Hiểu luồng nghiệp vụ và logic hệ thống
- Thực hành **kiểm thử chức năng thủ công**
- Thiết kế test case và ghi nhận lỗi
- Làm quen với quy trình phát triển phần mềm (SDLC)

---

## Chức năng chính
- Quản lý sản phẩm và danh mục
- Quản lý nhân viên và phân quyền người dùng
- Xử lý bán hàng và hóa đơn
- Lưu trữ và truy xuất dữ liệu

---

## Phạm vi kiểm thử
- Phân tích yêu cầu chức năng
- Thiết kế test case cho các chức năng chính
- Thực hiện kiểm thử thủ công (Manual Testing)
- Ghi nhận và báo cáo lỗi phát sinh

---

## Công nghệ sử dụng
- Ngôn ngữ lập trình: C#
- Kiến trúc: MVC
- Cơ sở dữ liệu: SQL Server
- Công cụ: Microsoft Visual Studio
